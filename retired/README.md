# Retired plugins

Plugins that are no longer in the marketplace, kept with their tests, fixtures and notes as they
were on the day they were retired. Nothing here is installed, generated or tested by the scripts in
`scripts/`; the tests under each plugin's `tests/` ran against `plugins/<name>` paths and are not
expected to run from here.

| Plugin | Retired | Replaced by |
| --- | --- | --- |
| `delegation` | 2026-10-15 | [buildermesh](https://github.com/rickdiculousli/buildermesh): leads, executors and routines on a mesh, results by tree hash |
| `long-horizon` | 2026-10-15 | buildermesh: a goal is a long spec in the same place as any other |
